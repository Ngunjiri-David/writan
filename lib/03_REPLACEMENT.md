phone's model and Android version. Done when: one page naming each choice,
its runner-up and why; minimum Android version set from the two phones.

wireframes of Inbox, Today, a task, the morning page and the capture widget;
three directions at most, one chosen with a written reason.
Slice plan. Inputs: STATE, SPEC.md, the chosen toile. Done when: slices are
ordered, each one behavior and one test; the first fits in a day.
Cut (one card per slice). Inputs: STATE, the slice, the files it touches.
Done when: its test passes, the diff is reviewed, it is committed.
Fitting. Inputs: STATE, CODES.md, both phones. Done when: you've lived in it
for a week, your partner has used it five minutes unaided, and every snag is
fixed or written down with a reason.
Finishing. Inputs: STATE, CODES.md. Done when: the underside is done (empty
states, error copy, icon, haptic, 48 dp targets, reduced motion, font
scaling, dark mode) and the Ledger's "Begun" line is in.
Launch. Inputs: STATE, the launch checklist. Done when: the listing and
policies are checked against Play's current docs and the build is submitted.
